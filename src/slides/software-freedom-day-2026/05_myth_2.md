# Myth #2

## "Once a PEP is accepted, it's forever"

### False.

| PEP | What Happened |
|-----|---------------|
| PEP 3003 | Accepted, then replaced |
| PEP 572 | Accepted *despite* controversy; BDFL retired after |
| PEP 336 | Accepted, then never implemented |

**Acceptance != Consensus. Acceptance != Permanence.**
